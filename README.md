# Tryanks/libusb

Independent Go cgo bindings for the libusb-1.0 C library.

## Installation

```bash
go get github.com/Tryanks/libusb
```

The libusb C library must also be installed.

### macOS

```bash
brew install libusb
```

### Linux

```bash
sudo apt-get install -y libusb-dev libusb-1.0-0-dev
```

## Project history

Forked from [gotmc/libusb](https://github.com/gotmc/libusb); developed independently.
